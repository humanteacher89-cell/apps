🔊는 이 기기에 들어 있는 한국어 음성으로 읽어요. 수업 전에 '소리 확인'을 한 번 눌러 보세요.

소리가 안 나요?
  • 🔊는 기기에 설치된 한국어 음성을 써요. 한국어 음성이 없거나 앱이 음성 읽기를 막으면 소리가 안 나요.
  • 가장 간단한 방법: 링크를 복사해서 Chrome이나 Edge 브라우저에서 열기. 두 브라우저에는 한국어 음성이 들어 있어요.
  • 휴대폰: 아이폰은 Safari, 안드로이드는 Chrome 앱에서 링크 열기. 무음 모드와 음량을 확인해요.
  • Windows에 음성 설치: 설정 → 시간 및 언어 → 언어 → 언어 추가 → 한국어(음성 합성 포함) → 앱 다시 열기
  • Mac에 음성 설치: 시스템 설정 → 손쉬운 사용 → 읽어주기 → 시스템 음성 → 관리 → 한국어 내려받기
  • 그래도 안 되면 선생님이 직접 읽어 주세요. 게임은 소리 없이도 다 돼요.
