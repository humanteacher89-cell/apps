# 한글원샷 — 프랑스 한글학교 레벨별 자료 저장소

QR 한 번(원샷)에 내 레벨 자료가 열리는 **한 장짜리 페이지**. 교사들이 주제 → 상/중/하로 나눠 둔 자료를 페이지에서 로그인해 올리면 타일·띠·버튼으로 보여 준다. 구글시트는 뒤에서 자료를 담아 두는 곳일 뿐, 교사·학습자 누구도 시트를 보지 않는다. 학습자 쪽은 아무것도 저장하지 않는다.
홈 화면에 추가하면 주소창 없이 앱처럼 열린다(웹 앱 설정 `manifest.json` · `sw.js` · `icons/`).

## 파일
| 파일 | 무엇 |
|---|---|
| `index.html` | 페이지 전부(화면·글·동작, 한국어/프랑스어). 휴대폰 앱 모양(아래 탭: 홈·QR 코드·선생님), PC에서는 폰 폭(480px) 화면을 가운데에. 외부 파일은 QR 그리기(cdnjs qrcodejs)와 글꼴(jsdelivr Pretendard) 둘 |
| `config.js` | 설정: 앱스 스크립트 주소(`API_URL`), 제목, 레벨 설명, 자료 유형, 소속 학교 17곳(`SCHOOLS`) |
| `sample-data.js` | 견본 자료·견본 교사 코드. `API_URL`이 비어 있을 때(시험 모드)만 쓰인다 |
| `apps-script/Code.gs` | 구글시트에 붙이는 서버 코드(읽기·교사 로그인·올리기·숨기기) |
| `manifest.json` · `sw.js` · `icons/` | 홈 화면에 추가(앱 이름·아이콘·전체 화면). `sw.js`는 늘 인터넷에서 먼저 받고 끊겼을 때만 저장해 둔 화면을 쓴다 |
| `serve.py` | 로컬 확인용 서버(`python serve.py 8765` → http://127.0.0.1:8765/) |

## 로컬에서 보기
이 폴더에서 `python serve.py 8765`(맥·리눅스는 `python3`) 뒤 브라우저에서 http://127.0.0.1:8765/ (QR 그리기만 인터넷이 필요).
공개 주소: https://humanteacher89-cell.github.io/apps/hangeul-oneshot/ (`apps` 저장소의 이 폴더가 그대로 공개된다. 폴더 이름 = 주소라 바꾸지 않는다).
시험 모드 교사 코드: 1234(김선생·파리), 5678(이선생·리옹). 올린 자료는 그 브라우저의 localStorage에만 남는다.

## 실제 시트와 연결하기 (휴먼쌤, 한 번)
1. 구글시트 새로 만들기 → 확장 프로그램 → Apps Script → `apps-script/Code.gs` 내용 붙여 넣기 → 저장.
2. 함수 `setup` 실행(권한 허용) → 탭 자료·주제·교사·설정이 생긴다.
3. 배포 → 새 배포 → 웹 앱 → 실행 사용자 '나', 액세스 '모든 사용자' → 주소(…/exec) 복사.
4. `config.js`의 `API_URL`에 그 주소를 넣는다. 끝. **시트는 아무와도 공유하지 않는다**(스크립트가 휴먼쌤 이름으로 읽고 쓴다).
5. '교사' 탭에 이름·코드를 적는다(학교 칸은 처음 골라져 있을 학교, 비워도 된다). 코드를 받은 교사만 페이지에서 로그인해 올릴 수 있다.

## 시트 '자료' 탭 열
id · 묶음 · 주제 · 레벨(상/중/하) · 제목 · 유형 · 링크 · 설명 · 시간 · 학교 · 올린이 · 올린날짜 · 공개(N이면 숨김)
페이지에서 올리면 id·올린이·올린날짜는 자동, 학교는 교사가 올리기 화면에서 고른 이름(`config.js` SCHOOLS의 한국어 이름). 휴먼쌤이 시트에서 직접 고칠 때는 id를 비워도 된다(화면에서는 줄 번호로 구분).
'주제' 탭(선택): 주제 · 프랑스어 · 묶음 · 순서 · 아이콘(이모지 하나, 비우면 주제 이름으로 자동). '설정' 탭: title · subtitle · notice(첫 화면 안내 한 줄).

## 자료 형식 (2026-10-07)
- **자료 = 링크 하나.** 직접 만든 사이트·구글 드라이브·구글 문서/슬라이드/설문·유튜브 무엇이든 링크 하나로 받고, 학습자에게는 모두 같은 카드(제목·유형·시간·학교)로 보인다.
- 올리기 화면이 링크를 알아보고 한 줄로 알려 준다: 드라이브 파일·문서(공유 설정 안내), 드라이브 폴더(파일 하나 링크 권함), 사본 만들기 링크(구글 계정 필요), http 주소(https 권함). 내 컴퓨터 주소(localhost 등)나 https로 시작하지 않는 글은 올라가지 않는다.
- 직접 만든 사이트는 공개 주소(https://…)가 있어야 한다.

## 지킬 것
- 자료 링크(드라이브 파일)는 '링크가 있는 모든 사용자 보기'로 공유해야 학습자가 연다.
- QR은 종이 한 장에 하나씩(여러 개가 가까이 있으면 카메라가 헷갈린다). 인쇄 화면이 한 장에 한 개씩 뽑는다.
- 교사 로그인은 '코드' 하나로 하는 간단한 방식이다(비밀번호 수준의 보안은 아님). 코드가 새면 시트에서 그 교사 코드를 바꾸면 된다.
- 주소(해시) 모양: `#/t/주제` 주제 화면, `#/t/주제/하` 레벨 바로 열기(레벨 QR), `#/qr` 첫 화면 QR과 주제 목록, `#/qr/주제` 주제·레벨 QR 인쇄, `#/login` `#/mine` 선생님 탭, `#/upload/주제/레벨` 자료 올리기(주제·레벨 미리 채움).
- 주소로 처음 들어오면(QR) 주제 화면 위에 'QR로 바로 왔어요'가 잠깐 보인다. 학습자 쪽은 언어·레벨 어느 것도 저장하지 않는다.
- 홈 화면 추가 안내는 첫 화면에만, 휴대폰에서만 보인다(안드로이드 크롬은 '추가' 단추, 아이폰은 공유 버튼 안내). 이미 앱으로 열었으면 보이지 않는다. 실제로 설치되려면 공개 주소(https)여야 한다.
- 학교를 더하거나 빼려면 `config.js` SCHOOLS만 고친다(XR개발부 '프랑스 한글학교 로비' 17곳과 같은 목록).
