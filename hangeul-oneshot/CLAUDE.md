# 한글원샷 — 프랑스 한글학교 레벨별 자료 저장소

QR 한 번에 내 레벨 자료가 열리는 **한 장짜리 페이지**(서비스가 아니다). 교사들이 주제 → 상/중/하로 나눈 자료를 페이지에서 로그인해 올리면, 페이지가 타일·띠·버튼으로 보여 준다. 구글시트는 뒤에서 자료를 담는 곳일 뿐이다. 학습자 쪽은 아무것도 저장하지 않는다.
사용자는 **휴먼쌤**이라고 부른다. 답은 한국어로, 휴대폰에서 읽기 쉽게 결과부터 짧게. 이모지는 쓰지 않는다.
이 폴더는 `apps` 저장소(휴먼쌤 작은 앱 모음)의 `hangeul-oneshot/`이다. 공개 주소 https://humanteacher89-cell.github.io/apps/hangeul-oneshot/
클라우드 세션(claude.ai/code)이나 다른 곳에서 이 폴더를 고칠 때 아래를 따른다. 경로는 모두 이 폴더 기준이다.

## 무엇이 어디에
| 경로 | 무엇 |
|---|---|
| `index.html` | 페이지 전부(화면·글·동작, 한국어/프랑스어). 휴대폰 앱 모양(아래 탭 3개), PC는 480px 폭 가운데. 외부 파일은 QR 그리기(cdnjs qrcodejs)와 글꼴(jsdelivr Pretendard) 둘 |
| `config.js` | 설정: 앱스 스크립트 주소 `API_URL`(비우면 시험 모드), 제목, 레벨 설명, 자료 유형, 소속 학교 17곳 `SCHOOLS` |
| `sample-data.js` | 시험 모드 견본 자료·견본 교사 코드(1234, 5678). 실제 운영에는 쓰이지 않는다 |
| `apps-script/Code.gs` | 구글시트에 붙이는 서버 코드(읽기·교사 로그인·올리기·숨기기). 시트 쪽에 붙여 넣어 배포한다(이 저장소에서는 실행되지 않음) |
| `manifest.json` · `sw.js` · `icons/` | 홈 화면에 추가하면 주소창 없이 앱처럼 열리게(이름·아이콘·전체 화면). `sw.js`는 네트워크 먼저, 끊겼을 때만 저장본. 다른 주소(시트 서버·CDN)는 건드리지 않는다. 화면 파일을 크게 바꿨는데 옛 화면이 남으면 `sw.js`의 `CACHE` 이름 숫자를 올린다 |
| `serve.py` | 로컬 확인용 서버(`python3 serve.py 8765`) |
| `README.md` | 설치·시트 양식·지킬 것 |

## 동작 요약
- 화면은 **휴대폰 앱 모양**이다(휴먼쌤 2026-10-07 결정: "앱 같지 않다" → 모바일 시안 A안 '밝고 귀여운 학습 앱'). 크림색 바탕, 둥근 카드, 하·중·상 큰 버튼, 아래 탭(홈·QR 코드·선생님). PC·태블릿용 배치를 따로 만들지 않는다.
- 주소(해시): `#/` 첫 화면(묶음 칩 + 주제 카드) · `#/t/주제` 주제 화면(하·중·상 버튼 + 자료 카드) · `#/t/주제/하` 그 레벨로 바로(레벨 QR) · `#/qr` 첫 화면 QR과 주제 목록 · `#/qr/주제` 주제·레벨 QR(인쇄하면 한 장에 하나씩) + 아래 '자료별 QR' 목록 · `#/mq/자료id` 자료 하나의 QR(찍으면 그 자료 링크가 바로 열림) · `#/login` `#/mine` 선생님 탭 · `#/upload/주제/레벨` 자료 올리기.
- 자료별 QR(휴먼쌤 2026-10-07 저녁 요청): 주제 화면의 자료 카드마다 오른쪽에 QR 버튼. 누르면 그 자료 QR 하나가 크게 나오고 인쇄하면 한 장. QR에는 자료 링크 자체가 담긴다(학생은 찍으면 자료로 바로 감). 그래서 교사가 링크를 바꾸면 인쇄한 자료 QR은 옛 링크를 연다. 주제·레벨 QR은 그대로 있다.
- 주제 그림: 시트 '주제' 탭 '아이콘' 칸 → 없으면 `index.html`의 TOPIC_ICONS(주제 이름 낱말로 고름) → 없으면 첫 글자.
- 자료 읽기: `API_URL?action=data` → JSON. 올리기·숨기기: `API_URL`에 POST(JSON, 교사 코드 포함). `API_URL`이 비면 `sample-data.js` + localStorage로 흉내 낸다.
- 교사 로그인은 시트 '교사' 탭의 코드 하나로 한다(간단한 방식, 비밀번호 수준 아님). 로그인 상태는 교사 기기 localStorage에만 둔다.
- 시트는 뒤에서만 쓴다(휴먼쌤 2026-10-07): 교사·학습자 모두 페이지만 보고, 시트는 휴먼쌤 계정에만 둔다(공유 안 함). 화면에 '시트에 적으라'는 안내를 넣지 않는다.
- 소속 학교: 올리기 화면 맨 위에서 `config.js` SCHOOLS 17곳 중 고른다(XR개발부 '프랑스 한글학교 로비'와 같은 목록, 휴먼쌤 2026-10-07 지시). 시트에는 한국어 이름이 적힌다. 고른 학교는 교사 기기에 남아 다음에 먼저 골라져 있다.
- 자료 형식은 '링크 하나'로 통일한다(휴먼쌤 2026-10-07 고민 → 앱개발부 제안). 사이트·드라이브·문서·설문·유튜브 무엇이든 같은 카드로 보이고, 올리기 화면의 `linkCheck()`가 링크 종류와 고칠 점을 한 줄로 알려 준다. 못 여는 링크(내 컴퓨터 주소, https 아님)는 막는다.
- 홈 화면에 추가: 첫 화면에 안내 카드(휴대폰에서만, 이미 앱으로 열었으면 숨김). 안드로이드 크롬은 `beforeinstallprompt`로 '추가' 단추, 아이폰은 공유 버튼 안내. 닫기는 저장하지 않는다(학습자 쪽 저장 없음).

## 배포가 되는 방식
- `apps` 저장소가 그대로 GitHub Pages로 공개된다. 이 폴더 = https://humanteacher89-cell.github.io/apps/hangeul-oneshot/ . `main`에 들어가면 1~2분 안에 반영. 폴더 이름(주소)은 바꾸지 않는다(QR이 이 주소를 담는다).
- **`main`에 바로 올리지 말고 새 브랜치 + PR**. 합치는 것은 휴먼쌤이 GitHub에서 한다. PR 설명은 한국어로 "무엇을 · 왜 · 어떻게 확인했는지 · 휴먼쌤이 폰에서 볼 곳".
- 앱스 스크립트 코드(`apps-script/Code.gs`)를 고쳤으면 PR 설명에 "시트 쪽 스크립트를 다시 붙여 넣고 새 버전으로 배포해야 함"이라고 적는다(자동 반영 안 됨).

## 지킬 것
- 비밀을 커밋하지 않는다: 교사 코드, 실제 시트 주소·ID, 개인 정보. `config.js`의 `API_URL`(앱스 스크립트 주소)은 공개되어도 되는 값이다(코드 없이는 쓸 수 없음).
- 글 파일은 모두 UTF-8(한글). 학습자 화면에는 저장·로그인·추적 기능을 넣지 않는다(휴먼쌤 결정: 아티팩트 수준의 자료 저장소).
- 레벨 글자는 시트 그대로 '하·중·상'. 새 기능은 먼저 휴먼쌤에게 묻는다.
- 휴먼쌤 PC에도 이 저장소의 사본이 있다. PC 쪽은 작업 전에 GitHub에서 먼저 받아오므로, 여기서 고친 것은 `main`에 합쳐지기만 하면 된다.

## 확인하는 법 (클라우드 환경에는 브라우저가 없을 수 있다)
- 문법: `node --check` 는 HTML 안 스크립트에 못 쓰니, 스크립트를 잠시 빼서 보거나 이 폴더에서 `python3 serve.py 8765` 뒤 `curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8765/`가 200인지 본다. `config.js`·`sw.js`·`apps-script/Code.gs`(복사해 .js로)는 `node --check`, `manifest.json`은 JSON으로 읽어 본다. 화면은 휴먼쌤이 폰으로 확인한다.
- 공개 주소 확인(`*.github.io`)은 클라우드 기본 네트워크에서 막힐 수 있다(환경의 네트워크를 Custom으로 바꾸고 `*.github.io`를 허용해야 함).
- 시험 모드 동작은 `config.js`의 `API_URL`을 비운 채 본다. 실제 시트 연결은 휴먼쌤 계정이 필요하다.
